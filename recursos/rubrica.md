# 🧾 Rúbrica de evaluación — Uso de Git y GitHub

[⬅️ Índice](../README.md)

Rúbrica analítica aplicable al **Lab 4** o a cualquier trabajo grupal de DSY1102 entregado mediante GitHub. Puede usarse como componente de la nota del proyecto (sugerido: 15–20 %).

| Indicador | Muy bueno (100 %) | Bueno (75 %) | Suficiente (50 %) | Insuficiente (0–25 %) | Peso |
|-----------|-------------------|--------------|-------------------|-----------------------|:----:|
| **1. Estructura del repositorio** | README completo (descripción, ejecución, integrantes, diagrama). `.gitignore` adecuado; sin compilados ni secretos | README con datos básicos; `.gitignore` presente | README mínimo o `.gitignore` incompleto (algunos compilados subidos) | Sin README ni `.gitignore`; carpeta `out/`/`.class` en el repo | 15 % |
| **2. Calidad de los commits** | Commits pequeños, frecuentes y con un propósito; mensajes en imperativo y descriptivos | Mayoría de commits claros; algunos mezclan temas | Pocos commits grandes o mensajes genéricos (“avance”) | 1–2 commits con todo el proyecto, o mensajes sin sentido | 20 % |
| **3. Uso de ramas** | Cada funcionalidad en una rama con nombre convencional; ramas eliminadas tras fusionar | Usa ramas para la mayoría del trabajo | Usa ramas ocasionalmente; trabajo directo en `main` | Todo en `main` | 15 % |
| **4. Pull Requests y revisión** | Cada PR con descripción, issue enlazado y revisión con comentarios útiles y respetuosos; evidencia de correcciones tras review | PR con descripción y aprobación, pocos comentarios | PR sin descripción o aprobados sin revisión | Sin PR | 20 % |
| **5. Participación equitativa** | Todos los integrantes con aportes significativos y distribuidos en el tiempo (Insights → Contributors) | Participación de todos, levemente desbalanceada | Un integrante concentra la mayor parte | Integrante(s) sin commits | 15 % |
| **6. Integración y estado de `main`** | `main` compila y funciona; conflictos bien resueltos; tag de entrega publicado | `main` compila; detalles menores | `main` compila con advertencias o marcadores de conflicto en comentarios | `main` no compila o tiene marcadores `<<<<<<<` | 15 % |

**Nota:** la participación (indicador 5) puede ponderarse individualmente para ajustar la nota de cada integrante.
